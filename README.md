# Mission Health

An astronaut health monitoring prototype by **Bug Busters / NASA Space Apps**.

**Live website:** https://mission-health-bug-busters.vercel.app/

## Features

- Health readings, including heart rate, blood oxygen, temperature and trends.
- NasaGPT chat for questions and explanations.
- Audio and video diary with transcription and analysis.
- Personal archive with search and answers based on saved records.
- Reminders, scheduled tasks and an astronaut group chat.
- NASA research data and ECG recordings.

The app supports English and Urdu, light and dark themes, and mobile screens.

Readings come from user entries and imports. Generated samples are labeled.
